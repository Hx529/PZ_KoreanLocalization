Hx 번역 모드 목록

[Hx] 모드 한글화 - 통합 번역에 번역이 들어 있는 창작마당 모드입니다. 모드 매니저에서 통합 번역을 가장 아래에 두어야 번역이 적용됩니다.

범용 사용 통합 번역은 바닐라 번역 키를 덮어쓰지 않으므로 어떤 모드 조합에서도 켜 두면 됩니다.

무들·특성 설명, 로딩 화면 팁처럼 바닐라 문구 자체를 바꾸는 모드를 쓸 때만 (선택형) 바닐라 문구 변경 모드용을 통합 번역보다 아래에 켜 주세요.

호환성 및 덮어쓰기 주의

각 모드의 mod.info에 적힌 incompatible= 선언과 번역 키를 비교한 결과입니다. 제작자가 선언하지 않은 실제 플레이 충돌은 포함되지 않습니다.

번역 키 수는 해당 모드의 문구 중 통합 번역에 들어 있는 개수입니다(영문 번역 키, 모드 옵션 화면 문구, 편지·쪽지 본문 포함). 원본: 저장소의 MODS.md
